# 範本檔案說明

這個資料夾在本地skill包裡應包含兩份老師的官方範本:

- `111_SA.docx`(111-113學年度版範本)
- `114_SA.docx`(114學年度後版範本)

**這兩個檔案在這個public repo裡被 `.gitignore` 排除,不會出現在GitHub上。**

原因:這兩份是授課教師的課程教材,不是本repo作者的原創內容,公開分享前應先取得授課教師同意。

如果你是為了實際使用這個skill(不只是瀏覽程式碼),需要自行向授課教師索取官方範本,並放入這個資料夾,檔名比照上方即可,`SKILL.md`與`reference/`裡的規則會自動對應這兩個檔名。
