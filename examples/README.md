# 範例檔案說明

本地skill包可能包含一份透過指導教授取得的歷屆優秀範例(真實學生的畢業專題文件),供Claude生成內容時對照真實案例的寫作手法與格式呈現。

**這份檔案在這個public repo裡被 `.gitignore` 排除,不會出現在GitHub上。**

原因:這是他人(非本repo作者)的畢業專題成果,版權與隱私屬於原作團隊,即使透過指導教授取得,也不適合未經同意公開轉發。

若要自行補上類似的參考範例,可以放進這個資料夾,並在SKILL.md裡更新對應的檔名引用。沒有這份檔案不影響skill的核心功能——`reference/`裡的規則檔案已經是從範例中萃取整理出的通用規則,足以支撐日常使用。
